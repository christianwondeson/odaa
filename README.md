# Under the Odaa (በኦዳ ዛፍ ሥር)

A 60–90 s illustrated short film (9:16 and 16:9), narrated in Amharic (with Afaan Oromoo experiment) and bilingual **Amharic + English** titles and subtitles, generated by a multi-stage pipeline around one contract: `storyboard.json`.

## Run (one command, cross-platform)
```bash
pip install -r requirements.txt && cp .env.example .env   # fill in keys: see docs/ACCOUNTS.md
python -m pipeline.check_env        # verify credentials (never prints keys)
python -m pipeline.validate         # validate storyboard.json contract & review flags
python -m unittest discover -s tests # run offline pipeline unit tests
python -m pipeline.smoke_test       # one call per provider, logs latency to runs.jsonl
python -m pipeline.benchmark_tts --include-existing  # compare TTS providers on shots 08 & 09
python -m pipeline.run radio        # validate -> narration -> subtitled radio cut
python -m pipeline.run              # validate -> narration -> keyframes -> shots -> music -> 9:16 + 16:9 film
python -m pipeline.assemble mobile  # optional 720p (~11-12 MB) WhatsApp/Telegram share copy from 9:16 film
```
Or with `make` (Linux/macOS): `make env-check`, `make smoke`, `make radio`, `make film`, `make radio NARRATION_LANG=oro`.

Outputs: `outputs/final/film_9x16.mp4`, `film_16x9.mp4` (`~21 MB` at 1080p; plus `film_9x16_mobile.mp4` `~11.7 MB` when `assemble mobile` is run, and `*_oro.mp4` variants), and `radio_cut_<lang>.mp4`. Narration lives in `outputs/narration/<lang>/`. Bilingual opening title, `<lang> + en` subtitles, and AI end card are burned into every export. Requires `ffmpeg` with `libass` and `Ebrima` (or Ethiopic-capable system font).

## Stages (each reads `storyboard.json`, writes `outputs/<stage>/`)
| Stage | Script | Model / tool | Runs where |
|---|---|---|---|
| script | `pipeline/script.py` | Storyboard contract / Gemini text draft | local / API |
| narration | `pipeline/narration.py` | Gemini 3.8 Flash TTS (auto-fallback), optional `TTS_PROVIDER=hasab\|addis\|auto` | API |
| tts benchmark | `pipeline/benchmark_tts.py` | A/B compare Gemini vs. Hasab AI vs. Addis AI into `outputs/benchmarks/tts/` | API |
| keyframes | `pipeline/keyframes.py` | FLUX.2 klein 4B on Cloudflare Workers AI | API |
| moving shots | `pipeline/shots.py` | Wan 2.2 (`outputs/wan/`, Kaggle notebook or optional WaveSpeed), else eased FFmpeg Ken Burns | Kaggle / API / local |
| music | `pipeline/music.py` + `notebooks/` | ACE-Step 1.5 cue sheet + Kaggle notebook or WaveSpeed (`--generate`) | Kaggle / API |
| assembly | `pipeline/assemble.py` | FFmpeg (xfade, ducking, bilingual title/subs, loudnorm, end card) | local |
| runner | `pipeline/run.py` | One-command end-to-end orchestrator | local |
| mcp server | `pipeline/mcp_server.py` | Optional MCP tool wrapper (`python -m pipeline.mcp_server`) for agents | local |

Change one shot in `storyboard.json` and re-run: only that shot's stage outputs regenerate (hash of inputs, `outputs/.cache.json`).

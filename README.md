# Under the Odaa

A 60–90 s illustrated short film (9:16 and 16:9), narrated in Afaan Oromoo with English subtitles,
generated by a five-stage pipeline around one contract: `storyboard.json`.

## Run
```bash
pip install -r requirements.txt && cp .env.example .env   # fill in keys: see docs/ACCOUNTS.md
make env-check  # which credentials are set
make smoke      # one call per provider, logs latency to runs.jsonl
make radio      # validate -> narration -> radio cut (narration over placeholder pad on black)
make radio NARRATION_LANG=oro  # same, in Afaan Oromoo (default is am = Amharic, officially supported by Gemini TTS; oro = Afaan Oromoo)
make film       # validate -> narration -> keyframes -> shots -> music cues -> final edit
```
Outputs: `outputs/final/film_9x16.mp4`, `film_16x9.mp4`, `radio_cut_<lang>.mp4`. Narration lives in `outputs/narration/<lang>/`. English subtitles are used in every version. Requires `ffmpeg` with libass.

## Stages (each reads `storyboard.json`, writes `outputs/<stage>/`)
| Stage | Script | Model / tool | Runs where |
|---|---|---|---|
| narration | `pipeline/narration.py` | Gemini TTS | API |
| keyframes | `pipeline/keyframes.py` | FLUX on Cloudflare Workers AI | API |
| moving shots | `pipeline/shots.py` | Wan 2.2 clips if present in `outputs/wan/`, else FFmpeg Ken Burns | Kaggle / local |
| music | `pipeline/music.py` + ACE-Step notebook | ACE-Step 1.5 | Kaggle / Colab |
| assembly | `pipeline/assemble.py` | FFmpeg (duck, subtitles, loudnorm, end card) | local |

Change one shot in `storyboard.json` and re-run: only that shot's stage outputs regenerate (hash of inputs, `outputs/.cache.json`).

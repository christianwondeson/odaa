# User test protocol (real people only; never invent feedback)
Radio cut (3+ from the audience): play once without comment. Ask: what happened? what did you feel? where did you get lost? which line stayed? Record verbatim notes + what you changed in storyboard.json (commit the diff).
Near-final cut: same questions plus: is the girl the same person throughout? did the ending land? subtitles readable on a phone?
